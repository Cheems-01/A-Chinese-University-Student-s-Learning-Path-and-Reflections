# 倒计时 / Countdown

一个单文件的网页倒计时器。双击 `index.html` 就能用，不联网、不装软件、不需要服务器。

## 文件

| 文件 | 说明 |
| --- | --- |
| `index.html` | 全部代码。HTML 结构、CSS 样式、JavaScript 逻辑都写在这一个文件里，19.6 KB |
| `README.md` | 就是你正在看的这份说明 |

## 怎么用

1. 双击 `index.html`，用浏览器打开。
2. 点上面「快捷时长」里的一档 —— 1 / 3 / 5 / 10 / 25 / 45 分钟，点了就直接开始。
3. 或者自己在下面填「小时 / 分钟 / 秒」，再点「开始倒计时」。
4. 中途可以「暂停 / 继续」，也可以「重置」回满格。
5. 走完会响三声提示音、画面闪一下、标签页标题变成「时间到！」。

## 快捷键

| 键 | 作用 |
| --- | --- |
| `空格` | 开始 / 暂停（结束后按下 = 重新开始） |
| `R` | 重置 |

在时、分、秒输入框里打字时，快捷键不会误触发。

## 界面在说什么

- **圆环**：一圈代表整段时间，剩多少就亮多少。最后 25% 变琥珀色，最后 10 秒变红并且数字开始呼吸。
- **环里的数字**：剩余时间。超过一小时会变成 `时:分:秒`。
- **环下的小字**：当前状态 —— 等待开始 / 倒计时中 / 已暂停 / 时间到。

## 实现上值得一提的几点

**计时用的是「结束时刻」，不是「每次减一秒」。**

```js
state.endAt = Date.now() / 1000 + state.remain;                 // 开始时记下终点
state.remain = Math.max(0, state.endAt - Date.now() / 1000);    // 每帧反算剩余
```

常见写法是 `setInterval(() => left--, 1000)`，那种写法在标签页被挂起、系统卡顿时会越走越慢，跑十分钟能差出十几秒。按终点反算就不会漂。

**圆环进度用 SVG 的 `stroke-dashoffset`。**

周长 `2πr`，剩余比例乘以周长就是该「藏起来」的长度，一帧改一个数字，浏览器自己插值。

**提示音是现场合成的。**

```js
osc.type = "sine";
osc.frequency.setValueAtTime(880, t0);              // 三声，最后一个升到 1046.5 Hz
gain.gain.exponentialRampToValueAtTime(0.0001, t0 + 0.5);
```

用 Web Audio 生成正弦波包络，所以不需要 mp3/wav 文件，整个页面没有任何外链资源。

**会记住上次设的时长。** 写在 `localStorage` 的 `countdown.last`，下次打开还是它。

**手机上不熄屏。** 计时中用 Screen Wake Lock API 申请保持屏幕常亮；浏览器不支持或被拒绝就静默跳过，不影响计时。

## 已知限制

- **关掉页面/标签，计时就没了**，刷新也会重置。它是计时器，不是闹钟——要「关了页面还能响」，得做成 PWA 并接通知。
- **提示音第一次可能没声音**：浏览器要求页面先被用户点过才允许出声。点「开始」就已经满足了；但用空格键启动时，某些浏览器判定「没有用户手势」，就会静默。
- 没有后台常驻，也没有多设备同步。

## 桌面快捷方式（Windows）

不想每次开浏览器再找文件的话，可以建一个 Edge 应用模式窗口的快捷方式：

```
目标: C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe
参数: --app="file:///你的路径/index.html"
```

`--app` 会开一个没有地址栏和标签栏的独立窗口，看起来就像一个真正的小应用。
